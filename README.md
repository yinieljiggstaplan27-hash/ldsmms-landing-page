# Long Distance Student Management — Sign-in Page

This folder contains a clean, modern sign-in page for the Long Distance Student Management and Monitoring System.

Files added:

- `index.html` — the sign-in page (open in a browser)
- `styles.css` — styles for the split layout and components
- `assets/logo.svg` — placeholder branded logo

To preview locally, open `index.html` in your browser (no server required).
